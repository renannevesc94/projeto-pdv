# Projeto PDV (Ponto de Venda)

## Sobre o Projeto

Este projeto implementa um sistema de Ponto de Venda (PDV) para gerenciamento de vendas. O sistema utiliza tecnologias robustas para garantir performance, escalabilidade e uma experiência de usuário eficiente.

## Tecnologias Utilizadas

### Front-end

- **React**: Biblioteca para construção de interfaces de usuário.
- **TypeScript**: Tipagem estática para maior segurança e robustez no código.

### Back-end

- **NestJS**: Framework para construção de APIs escaláveis e de alta performance.
- **PostgreSQL**: Banco de dados relacional utilizado para persistência de dados.
- **Prisma**: ORM moderno e intuitivo para manipulação do banco de dados.
- **Docker e Docker Compose**: Contêineres para facilidade de configuração e implantação do projeto.

- **Jest**: Framework de testes para garantir qualidade no desenvolvimento.
